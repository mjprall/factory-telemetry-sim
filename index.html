    How it works

    1. Simulate. Each machine emits one frame per tick: nominal value + duty cycle + mean-reverting drift + Gaussian noise + any injected fault.
    2. Transport. A network model can add jitter, so frames arrive out of order. A per-machine reorder buffer releases them by sequence number and gives up on gaps after 5 s.
    3. Detect. Every signal keeps an O(1) rolling mean/std. A sample's z-score is computed against the baseline before it is added, and anomalous samples are not learned. Hard engineering limits back it up.
    4. Debounce. Alerts need N consecutive samples to raise and 8 to clear, with a hysteresis band (clear below 0.75·z), so they don't flap. No data for 6 s → STALE.

    The shaded band on each chart is the learned mean ± z·σ envelope; dots mark samples while a signal is in WARN/ALARM.
